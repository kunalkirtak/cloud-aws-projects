# Amazon EC2 Overview

Amazon EC2 (Elastic Compute Cloud) provides resizable virtual servers in the cloud. An EC2 instance is a virtual machine that runs an operating system and your applications.

You choose an instance type that defines CPU, memory, storage and network capacity. Instances are launched from an Amazon Machine Image (AMI).

A security group acts as a virtual firewall for an instance. Security groups control inbound and outbound traffic by port, protocol and source.

An IAM role can be attached to an EC2 instance through an instance profile. Applications on the instance then receive temporary credentials automatically, so no access keys need to be stored on the server.

Instances are billed while they are running, so stop or terminate instances you no longer need.
